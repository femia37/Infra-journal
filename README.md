# Infrastructure Journal

Notes, incidents, and configuration from building and running
my own Linux server.

## Stack
- Ubuntu 26.04 LTS on a Vultr VPS
- Hardened SSH (key-only, root login disabled)
- ufw firewall

## Structure
- `incidents/` — things that broke, and how I diagnosed them
- `builds/` — what I built and why
- `stack/` — configuration files
